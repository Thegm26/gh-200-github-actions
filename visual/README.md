# Visual course

Use the live [GitHub Pages course](https://thegm26.github.io/gh-200-github-actions/) for the quickest start.

For offline use, after cloning/downloading and unzipping, open `visual/index.html` from your files in a modern browser. It is self-contained and works with `file://`; no install, account, network request, or server is required.

Optional local URL (from the repository root):

```sh
node _internal/scripts/serve-course.mjs
# http://127.0.0.1:4173
```

The same relative assets work from the GitHub Pages project URL. Browser state remains local to the browser/origin.
