# Official Microsoft Learn routes

These are original route notes, with the official pages linked below rather than copied.

- [Part 1: Automate your workflow with GitHub Actions](https://learn.microsoft.com/en-us/training/paths/github-actions/) introduces Actions automation, continuous integration, deployment concepts, and GitHub Script. In this repository, use exercises 01–08 for workflow fundamentals and the question bank's workflow/API scenarios for retrieval practice.
- [Part 2: Automate your workflow with GitHub Actions](https://learn.microsoft.com/en-us/training/paths/github-actions-2/) continues with package publishing, custom actions, and enterprise management. Use exercises 09–17, the action and enterprise sections of the question bank, and the linked GitHub Docs for product detail.

Azure deployment, package publication, and GitHub Script are useful supplemental hands-on topics. They are not presented as a replacement for the official GH-200 objective list; follow least privilege and use a disposable repository/account when doing a real cloud or publishing exercise.
