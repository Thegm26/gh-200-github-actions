# Sources and authority boundaries

## Primary technical sources

- [Microsoft Learn: GH-200 study guide (skills measured January 2026)](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/gh-200) — blueprint and weighting authority.
- [GitHub Docs: Actions](https://docs.github.com/actions) — technical behavior authority.
- [Workflow syntax](https://docs.github.com/actions/writing-workflows/workflow-syntax-for-github-actions), [events](https://docs.github.com/actions/writing-workflows/choosing-when-your-workflow-runs/triggering-a-workflow), [contexts](https://docs.github.com/actions/learn-github-actions/contexts), [reusing workflows](https://docs.github.com/actions/sharing-automations/reusing-workflows), [workflow commands](https://docs.github.com/actions/using-workflows/workflow-commands-for-github-actions), [caching](https://docs.github.com/actions/using-workflows/caching-dependencies-to-speed-up-workflows), [artifacts](https://docs.github.com/actions/using-workflows/storing-workflow-data-as-artifacts).
- [Enterprise administration](https://docs.github.com/enterprise-cloud@latest/admin/managing-github-actions-for-your-enterprise), [runners](https://docs.github.com/actions/how-tos/manage-runners/self-hosted-runners), [REST Actions APIs](https://docs.github.com/rest/actions), [variables API](https://docs.github.com/rest/actions/variables), and [secrets API](https://docs.github.com/rest/actions/secrets).
- [Custom actions](https://docs.github.com/actions/sharing-automations/creating-actions), [Marketplace publishing](https://docs.github.com/actions/sharing-automations/creating-actions/publishing-actions-in-github-marketplace), [attestations](https://docs.github.com/actions/security-for-github-actions/using-artifact-attestations).

## Secondary preparation / learning sources

- [Koedinger et al., Learning is not a spectator sport](https://www.purdue.edu/retrievalpractice/assets/pdf/Koedinger_etal_2016.pdf) and [APA: interleaving](https://www.apa.org/ed/precollege/psychology-teacher-network/introductory-psychology/2012/09/learning-strategies) — **learning strategy**, used only for active recall/interleaving design.
- [Worked-example effect overview](https://www.education.com/reference/article/worked-example-effect/) — **learning strategy**, not technical authority.
- Community posts or exam reports — **anecdotal exam-experience sources** only; deliberately not used to define technical facts, question answers, or likely exam content.
