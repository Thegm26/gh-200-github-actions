# The final 60 minutes

Technical checklist links: [study guide](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/gh-200), [workflow syntax](https://docs.github.com/actions/writing-workflows/workflow-syntax-for-github-actions), [security hardening](https://docs.github.com/actions/how-tos/security-for-github-actions/security-guides/security-hardening-for-github-actions).

| Minutes | Activity |
| ---: | --- |
| 0–10 | From memory, write the five weights and `starter ≠ reusable ≠ composite`. Check BLUEPRINT only afterward. |
| 10–20 | Write a manual input, matrix, `needs` output, `GITHUB_ENV`, `GITHUB_OUTPUT`, cache/artifact distinction, and service health check. |
| 20–30 | Answer six enterprise/security questions: runner group, policy, secret scope, token/PAT/OIDC, SHA pinning, environment protection. |
| 30–40 | Read every prior missed quiz explanation; re-answer without choices. |
| 40–50 | Do `npm run quiz -- --count 10 --seed final --review-wrong`; investigate only misses. |
| 50–60 | Read CHEAT_SHEET headings, hydrate, stop. Sleep is a better trade than a new topic. |

Before the exam: distinguish an artifact from cache; a reusable workflow from composite action; a secret from variable; GITHUB_TOKEN from PAT/OIDC; a tag from full SHA; disable from delete; runner group from action policy; attestation generation from verification.
