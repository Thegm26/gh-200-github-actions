# Real hands-on GitHub Actions

Fork this repository, clone **your fork**, open it with `code .`, then follow the detailed [setup and safety guide](SETUP.md).

Each numbered folder is an inactive template. Read its README before copying anything into `.github/workflows`; make the stated change in your fork, inspect the new run, then clean up as instructed.

Start with [01 — your first workflow](01-first-workflow/README.md), then use the next link in each case. Templates do not run until you activate one in your fork.
