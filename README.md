# Learn GitHub Actions for GH-200

Choose one route:

1. **Visual guide:** open the live, install-free [GitHub Pages course](https://thegm26.github.io/gh-200-github-actions/). For an offline copy or local URL, see [visual/README.md](visual/README.md).
2. **Real hands-on:** [fork this repository](https://github.com/Thegm26/gh-200-github-actions/fork), clone your fork, open it in VS Code, and follow [hands-on/README.md](hands-on/README.md).

The visual course keeps progress in this browser. The hands-on route uses inactive templates until you deliberately copy one into your fork’s `.github/workflows`.

Maintainers: see [_internal/README.md](_internal/README.md).
