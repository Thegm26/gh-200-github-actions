# Official GH-200 objective index

Source: [Microsoft Learn — Study guide for Exam GH-200](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/gh-200), skills measured January 2026, page last updated 2026-02-05. This is an original navigation summary, not a downloaded copy of the page.

The five assessed domains are author and manage workflows, consume and troubleshoot workflows, author and maintain actions, manage GitHub Actions for the enterprise, and secure and optimize automation. The complete bullet-level practice mapping is maintained in [BLUEPRINT.md](../docs/BLUEPRINT.md). Use the study guide itself for the current scope and weighting.

This course does not promise an exam outcome. It teaches the published objectives through original questions, small local checks, and explicit notes where an actual GitHub organization, enterprise, cloud identity provider, or hosted run is required.
