# Boundary key

`GITHUB_ENV` makes an environment variable available only to later steps in the same job. `GITHUB_OUTPUT` plus a step `id` makes a step output. A job-level `outputs` mapping promotes it, and a dependent job reads `needs.<job>.outputs.<name>`. `GITHUB_STEP_SUMMARY` renders Markdown; it is not a data channel.

On a VM job, a published service port is reached on `localhost`. When the job itself runs in a container on the shared Docker network, use the service label and container port.
