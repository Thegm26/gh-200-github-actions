# Lab 02 — consume and troubleshoot

Start with canonical labs 09 and 11 in [COURSE.md](../../docs/COURSE.md), then use [04 — consume and troubleshoot run evidence](../../examples/04-consume-troubleshoot/README.md) and [06 — interleaved debugging](../../examples/06-interleaved-debugging/README.md) for near-transfer.
