Technical checklist links: [study guide](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/gh-200), [workflow syntax](https://docs.github.com/actions/writing-workflows/workflow-syntax-for-github-actions), [security hardening](https://docs.github.com/actions/how-tos/security-for-github-actions/security-guides/security-hardening-for-github-actions).

1. Complete each direct exercise check from [COURSE.md](COURSE.md), then revisit any missed topic.
2. Revisit only quiz misses with the mapped lab in [COURSE.md](COURSE.md).
3. Explain each distinction below without notes, then confirm with [CHEAT_SHEET.md](CHEAT_SHEET.md).
4. Use the optional sandbox only for hosted behavior you are authorized to test.

Before the exam: distinguish an artifact from cache; a reusable workflow from composite action; a secret from variable; GITHUB_TOKEN from PAT/OIDC; a tag from full SHA; disable from delete; runner group from action policy; attestation generation from verification.
